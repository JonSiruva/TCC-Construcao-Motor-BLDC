# Trabalho de Conclusão de Curso - Construção de Motores Brushless com Impressão 3D para Robôs Humanoides

Este repositório reúne arquivos, documentação e códigos utilizados na construção de um motor de corrente contínua sem escovas (BLDC) para o Trabalho de Conclusão de Curso do 4º ano de Ciência da Computação da Universidade Estadual do Oeste do Paraná (UNIOESTE) - Campus Cascavel.

## Arquivos Impressao

Contém os arquivos `.stl`, `.3mf` e o `.step` utilizados para impressão dos componentes do motor, também contém duas pastas de conteúdos auxiliares utilizados:

- Arquivos de impressão e montagem do suporte para enrolamento. [Site](https://www.printables.com/model/1677108-multi-strand-wire-dispenser-for-parallel-motorstat)
- Arquivos do gerador de .stl para parafusos, porcas e arruelas. [Site](https://www.printables.com/model/94761-nut-job-nut-bolt-washer-and-threaded-rod-factory)

## Códigos Testes

Contém os códigos utilizados para criação dos gráficos do teste de posicionamento do motor, bem como os `.ino` utilizados para os testes de velocidade, torque, resistência, posicionamento e operação do motor.
