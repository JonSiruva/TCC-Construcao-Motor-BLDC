6-Spool Multi-Strand Wire Dispenser — STL Package

This project contains a compact 3D-printable wire dispenser designed for parallel coil winding (e.g. BLDC stator winding with multiple strands in hand).

The dispenser keeps wires aligned and tensioned to prevent tangling during winding.

Included STL Files
- side_plate.stl
- crossbar.stl
- wire_guide.stl
- spool.stl
- lid.stl

Print the following number of parts:
- side_plate: 2×
- crossbar: 1×
- wire_guide: 1×
- spool: 6×
- lid: 1×

Required Hardware
- M8 threaded rod (~190 mm length)
- 4 washers (M8)
- 2 nuts (M8)
- 1 tension spring

Key Dimensions
- spool flange diameter: 50 mm
- spool usable width: 50 mm
- assembled tool size (W × H × D): 170 × 150 × 130 mm

Typical Use Case / designed and tested for:
- 6 strand parallel winding
- 26 AWG enamel copper wire
- BLDC stator winding applications (e.g. Mini-Cheetah style actuators)
